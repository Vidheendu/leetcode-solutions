## 📂 Repository Structure

Solutions are grouped by their primary topic, with each problem maintained in its own folder containing the solution and problem notes.

```text
leetcode-solutions/
├── Arrays/
├── Backtracking/
├── Binary-Search/
├── Dynamic-Programming/
├── Stack/
├── Strings/
├── Trees/
├── Graphs/
├── Linked-List/
├── Greedy/
├── scripts/
├── README.md
└── stats.json
```

*The folders listed above represent the intended organization; additional topic folders are added as needed.*

Each problem folder generally contains:


- `.cpp` — C++ solution.
- `README.md` — Problem description, approach, and complexity analysis when available.
