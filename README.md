# LeetCode Solutions

A collection of my **LeetCode solutions in C++**, organized topic-wise to make practicing Data Structures and Algorithms (DSA) easier.

[![Repository](https://img.shields.io/badge/Focus-DSA-success.svg)](https://github.com/Vidheendu/leetcode-solutions)

## 📂 Repository Structure

Solutions are grouped by their primary topic, with each problem maintained in its own folder containing the solution and problem notes.

```text
leetcode-solutions/
├── Arrays/
├── Backtracking/
├── Binary-Search/
├── Dynamic-Programming/
├── Stack/
├── Strings/
├── Trees/
├── Graphs/
├── Linked-List/
├── Greedy/
├── scripts/
├── README.md
└── stats.json
```

*The folders listed above represent the intended organization; additional topic folders are added as needed.*

## 🧩 Topics Covered

| Topic | Description |
|---|---|
| Arrays | Array traversal, manipulation, and optimization |
| Strings | String processing and character operations |
| Stack | Parentheses, stack operations, and sequence problems |
| Backtracking | Recursive search and generating combinations |
| Dynamic Programming | State transitions and optimization |
| Greedy | Locally optimal choices |
| Binary Search | Efficient searching in sorted data |
| Hash Tables | Hash maps, sets, and frequency counting |
| Two Pointers | Problems using two moving indices |
| Sliding Window | Contiguous subarray and substring problems |
| Linked Lists | Pointer-based data structures |
| Trees & Graphs | Traversal and graph algorithms |
| Sorting | Ordering and comparison-based techniques |
| Bit Manipulation | Bitwise operations and binary representations |

## 💻 Language

- **C++**

## 📁 Problem Format

Each problem folder generally contains:

```text
problem-folder/
├── problem-name.cpp
└── README.md
```

- `.cpp` — C++ solution.
- `README.md` — Problem description, approach, and complexity analysis when available.
